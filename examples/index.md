# Examples

Enter here for runnable public-API usage and a standalone application consumer.

- [inspect.rs](inspect.rs) — serialize a local project with the optional serde feature.
- [inspect_derived.rs](inspect_derived.rs) — expose derived property, reference and layer-coordinate path views as JSON.
- [Independent consumer](consumer/index.md) — a separate Cargo project with property inspection, bounded file input and optional JSON.
- [EffectCraft adapter](effectcraft/index.md) — experimental ecproj conversion and import reporting.
